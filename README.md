# HomeFlow · תקציב משק הבית

אפליקציית ווב פשוטה לניהול התקציב של משק בית עם חשבון משותף אחד. אין בה חלוקה לפי מי שילם ואין התחשבנות בין בני הזוג.

## מה יש בה
- **מסך ראשי**: הכנסות, הוצאות, כמה נשאר (הכנסות − הוצאות), תקציב חודשי עם פס התקדמות, תחזית לסוף החודש, חלוקת ההוצאות לפי קטגוריות (גרף טבעת) והשוואה לחודשים קודמים.
- **הוצאות**: בתחילת כל חודש נוצרת אוטומטית רשימת ההוצאות לפי הקטגוריות.
  - הוצאות קבועות (🔁) נכנסות עם הסכום שנקבע להן ומסמנים ✓ כשהן יורדות מהחשבון. עד אז הן נספרות כ"צפויות".
  - אפשר לשנות סכום בחודש מסוים בלי לשנות את ברירת המחדל.
  - הוצאות משתנות מופיעות ריקות ורק מזינים סכום. כפתור + מוסיף עוד הוצאה מאותו סוג (למשל כמה קניות בסופר).
- **הכנסות**: הכנסות קבועות חוזרות כל חודש, ואפשר להוסיף גם הכנסות חד־פעמיות.
- **הגדרות**: תקציב ברירת מחדל, ניהול קטגוריות והוצאות קבועות, הכנסות קבועות, וגיבוי ושחזור לקובץ JSON.

הנתונים נשמרים ב-localStorage של הדפדפן.

## פיתוח
```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות יחידה ללוגיקה
npm run build    # בדיקת טיפוסים ובנייה ל-dist/
```

מבנה הקוד:
- `src/lib`: מודל הנתונים והלוגיקה, בלי UI: יצירת חודש, חישובים, תובנות ושמירה.
- `src/components`: המסכים.
